# 💸 Калькулятор зарплаты с отгулами

Приложение, которое считает, **сколько денег вы теряете на отгулах** и **что получите на руки**
в месяц с учётом аванса 20 числа (туда входит премия 20%) и зарплаты 5 числа.

Ваши данные уже вшиты: оклад **79 000 ₽**, премия **20%**, надбавка за вредность
**≈ 136 ₽/раб. день** (посчитана из расчётных листов: 1896 ₽ / 14 дней и 3005 ₽ / 22 дня), НДФЛ 13%.

---

## Вариант 1 — как обычное приложение на компьютере (рекомендую)

### Windows (2 минуты)
1. Установите Python, если его нет: https://www.python.org/downloads/
   ⚠️ При установке **поставьте галочку «Add python.exe to PATH»**.
2. Скопируйте папку `app` куда угодно (например, `C:\Калькулятор`).
3. Дважды кликните **`setup_windows.bat`** — он сам установит нужную библиотеку
   и создаст ярлык **«Калькулятор зарплаты»** на рабочем столе и в меню Пуск.
4. Всё, дальше открываете его как обычную программу двойным кликом по ярлыку.

### Linux
```bash
pip install PySide6
./start_paycalc.sh            # или скопируйте paycalc.desktop в ~/.local/share/applications
```

### Мгновенный EXE-файл (совсем без Python)
Если хотите один файл `.exe`, который просто запускается:
```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name "Калькулятор зарплаты" app/paycalc.py
# готовый файл появится в dist\
```

## Вариант 2 — браузерный (ничего ставить не надо)

Файл **`калькулятор-зарплаты.html`** — то же самое в виде веб-страницы:
- **Windows:** ПКМ по файлу → «Открыть с помощью» → Chrome/Edge (или перетащите файл в окно браузера).
- **Телефон:** откройте файл из «Загрузок» → «Открыть в браузере».
- В Chrome можно сделать «приложением»: меню ⋮ → «Сохранить и поделиться» → «Установить как приложение»,
  тогда появится своя иконка на рабочем столе.

## Как пользоваться (оба варианта одинаково)

1. Выберите **год и месяц** — рабочие дни подставятся сами (производственный календарь РФ).
2. Напишите **сколько отгулов** взяли (можно 0.5 = полдня).
3. Смотрите:
   - 🧮 **сколько стоит один отгул** «на руки»;
   - 💰 **итог на руки**, потери за месяц и разбивку на аванс 20 числа / зарплату 5 числа;
   - 📆 табличку «было бы без отгулов vs факт».

Кнопка **«Пересчитать по расчётным листам»** подставляет вредность ≈136 ₽/день.
Галка **«Вредность фиксированная»** — если она не режется при отгулах.
Все настройки сохраняются (в браузере — в localStorage, в приложении — в файле `~/.paycalc.json`).

## Модель расчёта (упрощённая!)

- Аванс 20 числа = доля оклада + вся премия (премия считается от фактически отработанного);
- Зарплата 5 числа = остаток оклада + вредность − НДФЛ − доп. вычеты;
- Отгул «съедает» оклад за день, премию за день и (по умолчанию) вредность за день,
  но частично возвращается за счёт невыплаченного НДФЛ.

⚠️ Оценка приблизительная: точные суммы зависят от политики компании. Если бухгалтерия делит
выплаты иначе — подкрутите «долю оклада в авансе» и «НДФЛ», цифры пересчитаются.

## Проверка

Контрольный пример: 22 рабочих дня, 3 отгула → без отгулов ≈ 85 079 ₽, факт ≈ 73 478 ₽,
потеря ≈ 11 602 ₽ (~3 867 ₽ за день).
